A modern, responsive, high-end boutique hotel website for **Dar Gabriel**, a traditional riad in the historic Bab Souk quarter of Chefchaouen, Morocco.

---

## ✨ Features

- **Multilingual Support**: Seamless switching between French (FR), Spanish (ES), and English (EN).
- **Interactive Rooms Showcase**: High-resolution gallery & carousel displaying all 8 authentic guest room categories with official Booking.com rates (in MAD & EUR).
- **Direct Booking Engine**:
  - Direct booking modal with automatic 15% discount code (`GABRIEL`).
  - Dates, guest count, and room selection.
  - Generates pre-filled direct concierge emails.
- **Rooftop & Experience Section**: Highlights the 360° panoramic terrace overlooking the Rif mountains, traditional Moroccan breakfast, and homemade dinners.
- **Interactive Google Maps**: Integrated interactive map view centered on Dar Gabriel at Bab Souk.
- **Smooth Animations & Scroll**: Lenis smooth scrolling with luxury typography and Moroccan-inspired earthy color palette (`#1d3354`, `#e26d5c`, `#d4a373`).

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/ilyasabarri/Dar-Gabriel.git

# Navigate to the project directory
cd Dar-Gabriel

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Production Build

```bash
# Compile TypeScript and build for production
npm run build

# Preview production build locally
npm run preview
```
